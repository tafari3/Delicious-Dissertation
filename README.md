# Delicious Dissertation

Engineering repository for the University of Zimbabwe capstone project **Autonomous Cross-Platform Application Programming Interface (API) Security Testing and Misconfiguration Scanner for Zimbabwean Fintech and E-Government Systems**.

This repository will contain the implementation blueprint, scanner source, synthetic laboratory APIs, evaluation harness, evidence/reporting components, and reproducible research artefacts.

> Current state: repository bootstrapped. The authoritative Phase-0 implementation blueprint is being prepared on a dedicated planning branch before implementation begins.
